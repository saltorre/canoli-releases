# CANoli Releases

Official builds of **CANoli**, an AI-native CAN bus analysis and
visualization tool — the bridge between your CAN bus and your AI agent.

Download the latest build from the [Releases](../../releases) page:

| Platform | File |
| --- | --- |
| macOS (Apple silicon) | `CANoli-<version>-macos-arm64.dmg` — signed and notarized |
| Windows (x64) | `CANoli-<version>-windows-x64-setup.exe` — Authenticode signed |
| Linux (x86_64) | `CANoli-<version>-linux-x86_64.tar.gz` — GPG signed, with `SHA256SUMS` |

CANoli embeds no AI model: you bring your own agent, which connects over
MCP and drives the app.

This repository contains release artifacts only — no source code.

Feel free to report issues in this repository.
